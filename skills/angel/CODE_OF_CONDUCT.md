# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, focus on the work. Personal attacks, harassment, and identity-based derogatory speech are not welcome — in issues, pull requests, commit messages, or anywhere else the project is discussed.

To report a violation, use GitHub's [private security advisory](https://github.com/PropterMalone/NineAngel/security/advisories/new) (the same channel used for security reports — chosen because it routes private messages directly to the maintainers).
